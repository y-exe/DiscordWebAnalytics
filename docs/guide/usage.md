# ダッシュボードの使い方

[目次](../README.md)

## URLの形式

期間はすべて `m=YYYY-MM` クエリで指定します。省略した場合は最新の公開月、`m=all` で全期間です。

| ページ | URL |
| --- | --- |
| 統計 (`/?m=2026-10`) | `/` |
| 全期間の統計 | `/?m=all` |
| チャンネル一覧 | `/channels?m=2026-10` |
| チャンネル詳細 | `/channels/{channelId}?m=2026-10` |
| メンバー一覧 | `/members?m=2026-10` |
| メンバー詳細 | `/members/{userId}?m=2026-10` |
| 関係性グラフ | `/relation?m=2026-10` |
| 比較 | `/compare?m=2026-10` |

旧形式 (`/month/2026/10`、`/all`、`/month/latest`) はクエリ形式へのリダイレクトで存続します。Botが投稿するランキングリンクも旧形式のまま開けます。

## 月の切り替え

期間バーで「月別 / 全期間」を切り替えます。月選択のドロップダウンには発言があった月だけが出ます (直近24ヶ月を対象)。

URLの `m=` は全ページ共通のため、サイドバーでページを移動しても選択中の月が引き継がれます。

## 各ページの見方

| ページ | 見られるもの |
| --- | --- |
| 統計 | 月の活動量、総発言数、アクティブメンバー数、活動のヒートマップ |
| チャンネル | チャンネルごとの発言数と比率。詳細ページで日別推移と上位投稿者 |
| メンバー | メンバーごとの発言数ランキング。詳細ページで個人推移と構成比 |
| 関係性グラフ | メンバー間の「同じチャンネルや同じ時間帯のやり取り」をグラフで可視化。ノードをクリックで個別強調 |
| 比較 | 選んだ人同士の発言数・活動時間帯を並べて比較 |

## データの扱い

- 保存するのは送信日時・文字数・チャンネルのみで、メッセージ本文は保存しません。
- 削除されたユーザーやBotが特定できないアカウントは集計から自動除外されます。
- 管理者が指定した除外チャンネルや告知系チャンネルは集計から除外されます (ギルド設定による)。
